# Carrossel — Diagnóstico comercial

Post de 4 slides (1080 × 1350 px) no mesmo sistema visual das capas de LinkedIn:
Inter Tight na manchete, Instrument Serif itálica com gradiente na palavra do conceito,
linha de apoio em Inter com entrelinha larga.

| Arquivo | Slide |
|---|---|
| `slide-1.html` | Gancho — o problema do leitor |
| `slide-2.html` | A tese — por que o diagnóstico vem antes |
| `slide-3.html` | O que é analisado na operação |
| `slide-4.html` | O que a empresa recebe + chamada |
| `carrossel.html` | Os quatro em sequência (versão editável) |
| `carrossel-diagnostico.pdf` | Pronto para publicar como documento no LinkedIn |
| `png/` | Os quatro slides em 2160 × 2700 (2×) |

Cada fundo carrega um motivo do sistema: a curva do ciclo comercial (slides 1 e 4),
a cunha de gradiente aerografada (slide 2) e os anéis de escuta/alvo (slide 3).

## Antes de publicar

O texto vive no HTML de cada slide. Falta um dado concreto — um número, um caso, um
antes e depois — que só quem fez o diagnóstico pode escrever. O melhor lugar para ele
é o slide 2, logo abaixo da tese.
